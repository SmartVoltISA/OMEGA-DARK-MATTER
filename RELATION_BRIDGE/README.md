# RELATION BRIDGE

This directory is the controlled interface between `SmartVoltISA/RELATION-LAB` and `SmartVoltISA/OMEGA-DARK-MATTER`.

RELATION-LAB provides experimentally tested relational mechanisms and methodology. OMEGA-DARK-MATTER tests whether any of those mechanisms can produce dark-matter-relevant observables without circularly encoding the expected gravitational law.

The bridge is intentionally conservative: model-level results remain model-level results until an independent Ω-DM transfer experiment passes preregistered controls.
