# Ω-DM-028 — Geometry condition for inverse-square scaling

## Question
What geometric condition, beyond conserved radial flux, is required to obtain p=2 in 3D?

## H1
If the effective shell measure grows asymptotically as S(r) proportional to r^2, conserved radial flux produces p=2 even when the geometry is anisotropic but scale-preserving. If shell measure instead scales as r^(2+s), the response exponent shifts to p=2+s.

## H0
The response exponent is independent of the asymptotic shell-measure scaling.

## Construction
Use the identity G(r)=Q/S(r), with Q constant. Test shell measures S(r)=C*r^(2+s), for s in {-0.2, 0, +0.2}. No inverse-square response is inserted; it follows only from division by the measured shell measure.

The test also includes a scale-preserving anisotropy interpretation: fixed angular deformation changes C and angular distribution but not the radial exponent when the shell measure remains proportional to r^2.

## Acceptance
H1 is supported if fitted p tracks 2+s within numerical tolerance, while the s=0 case gives p=2.

## Scope
This is a structural mathematical isolation test. It does not establish that physical space or a gravitational relational medium has this shell measure.
