# Ω-DM-017 — Environmental Relational Response

Status: EXECUTED / EXPLORATORY

## Question

Do not model gravity as a pre-existing entity or force. Measure only how the observable relational state of an environment changes when a localized source condition is introduced.

## Core definition

Let E0 be the environment with the source condition absent and E1 the same environment with the source condition present.

The primary object is the differential environmental response:

`ΔR = R(E1) - R(E0)`

The experiment asks whether this response has a reproducible spatial law.

## Minimal model

A cubic 3D lattice is used as a neutral continuous/discrete relational medium. The environment variable `u(x)` is determined by nearest-neighbour relational coupling and fixed zero boundary conditions. A localized unit source is introduced at the central cell.

The source amplitude is fixed independently of distance. No inverse-square force, gravitational potential, mass, or gravitational constant is inserted.

## Measurements

1. Solve the source-present environment.
2. Compare with the source-absent baseline `u0=0`.
3. Compute shell-averaged response `Δu(r)`.
4. Estimate the radial response gradient `-d(Δu)/dr`.
5. Fit log(response) versus log(distance) over an interior range, excluding the source cell and boundary region.
6. Record goodness of fit and finite-size dependence.

## Falsification / interpretation rules

- A power law is not accepted from visual similarity alone.
- The exponent must be reported with fit range and R².
- Finite-size and discretization effects must be checked.
- A mathematical response law in this model is NOT evidence that physical gravity has been derived.
- The result only establishes what relational environmental response this specified model produces.

## Important distinction

The experiment does NOT ask "what is gravity?" and does NOT treat attraction as a primitive entity. It asks:

`localized condition -> change in environmental relations -> observable spatial response`

This is the relation-first measurement target for subsequent Ω-DM work.
