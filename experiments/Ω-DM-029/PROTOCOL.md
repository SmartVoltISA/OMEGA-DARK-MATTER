# Ω-DM-029 — Relational recovery of 3D shell scaling

## Question
Can the radial shell-growth exponent required by Ω-DM-028 be recovered from relations alone, without using coordinate positions during measurement?

## H1
A relation graph with 3D local connectivity contains enough intrinsic information to recover a shell measure S(r) ~ r^2 from graph distance, even after node labels are randomized.

## H0
The 3D shell-scaling signature cannot be recovered from the relation graph alone.

## Model
- Finite cubic local relation graph, side length n=101.
- Each node has local nearest-neighbour relations in the three coordinate directions.
- Node labels are randomly permuted before analysis.
- The analysis receives only the adjacency relation and a source node.
- No coordinate positions are used in distance or shell measurements.
- Relational distance is shortest-path distance on the graph.

## Measurement
For shell radii r=5..29, count nodes at graph distance r from the source. Fit log(shell_count) versus log(r). The asymptotic target for a 3D local graph is shell_count proportional to r^2.

## Controls
- Repeat with six independent random node permutations.
- Verify that permutation does not alter the recovered exponent.
- Do not infer physical spatial geometry from the result.

## Scope
This tests emergence/recovery of effective dimensional scaling from relational structure. It does NOT show that physical space is generated by relations, nor does it derive gravity or dark matter.
