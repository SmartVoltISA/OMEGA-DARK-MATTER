# Ω-DM-012 — Relational-only translation inertia no-go test

Date: 2026-09-11
Status: PREREGISTERED BEFORE CERTIFICATION

## Question

Can nonzero translational inertia emerge from an action that contains only relational differences between node coordinates, without adding an absolute-coordinate kinetic term or an externally assigned mass coefficient?

## Model

For a connected weighted graph with symmetric W_ij >= 0, define the purely relational action

S = integral dt [ T_rel - V_rel ]

T_rel = 0.5 * sum_(i,j) W_ij * (v_i - v_j)^2

V_rel = 0.5 * sum_(i,j) W_ij * (x_i - x_j)^2

The sums are over ordered pairs; the factor 0.5 avoids double counting.

The action depends only on pair differences. Therefore a uniform translation x_i -> x_i + a(t) leaves V_rel unchanged, and a uniform velocity shift v_i -> v_i + u leaves T_rel unchanged.

No absolute-coordinate term, no node mass parameter, and no inverse-square interaction is allowed.

## Primary prediction

For a uniform translation mode v_i = u for all i, every relational velocity difference is zero. Therefore the relational kinetic energy of the translation mode is exactly zero and the associated canonical momentum generated by the relational kinetic term is exactly zero.

H1: the relational-only action nevertheless yields a positive effective translational inertia for the collective mode.

H0: the effective translational inertia is zero to numerical precision for every connected graph.

## Certification test

Generate 100 independent connected weighted graphs.
N = 10, 20, 40 nodes.
Edge probability p = 0.20.
Weights uniform on [0.2, 1.0].
Seeds 20261201 through 20261300.

For each graph:
1. construct W;
2. evaluate T_rel for uniform velocity u=1;
3. evaluate the canonical momentum vector from the derivative of T_rel with respect to v;
4. compute the collective momentum P = sum_i p_i;
5. independently compute the Hessian of T_rel and its quadratic form on the uniform vector;
6. verify that all are zero within floating-point tolerance.

Primary tolerance: absolute value <= 1e-12.

## Controls

A positive control adds an explicit absolute kinetic term T_abs = 0.5 * m0 * sum_i v_i^2 with m0=1.0. The uniform mode must then have positive inertia.

A perturbation control uses a nonuniform velocity vector with zero mean. Its relational kinetic energy must be positive for every connected graph.

## Acceptance

PASS-H0 if all primary graphs satisfy zero translational inertia within tolerance, the positive control gives a nonzero result, and the nonuniform-mode control is positive.

FAIL-H0 if any primary graph produces a value above tolerance while controls execute correctly.

INCONCLUSIVE if graph generation, numerical differentiation, or controls fail.

## Scientific interpretation

This test does not address physical gravity directly. It tests a structural limitation of a purely relational action: if the action depends only on differences, the global translation mode is a null mode of the relational kinetic metric.

If H0 is confirmed, a relational theory that needs ordinary translational inertia must obtain it from an additional structure: an absolute/embedding kinetic term, an internal field carrying the missing mode, a boundary condition, or another mechanism. That additional structure becomes an explicit target for subsequent Ω-DM experiments.

No claim about dark matter, gravity, or physical equivalence principle is made by this experiment.
