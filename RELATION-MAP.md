# Ω-DM RELATION MAP

## Purpose

This file stitches together the existing SmartVoltISA research that concerns **relations, connections, edges, interaction, relational state, emergent structure, propagation and network effects**.

The source material remains in its original repositories. This repository links to the original evidence instead of silently copying it and changing its provenance.

## Core chain

```text
DISTINCTION
    ↓
RELATION / CONNECTION
    ↓
PROPERTIES OF RELATION
    ↓
MULTIPLE RELATIONS
    ↓
INTERACTION
    ↓
RELATIONAL STATE
    ↓
STABLE CONFIGURATION
    ↓
STRUCTURE
    ↓
EMERGENT NODE / OBJECT
    ↓
PROPAGATION / DYNAMIC RESTRUCTURING
    ↓
OBSERVABLE EFFECT
```

For Ω-DM the proposed extension is:

```text
hidden relational structure
        ↓
relational state / interaction
        ↓
effective dynamical contribution
        ↓
gravitational-scale observable
        ↓
comparison with dark-matter models
```

This is a research hypothesis, not an established physical conclusion.

The current candidate property family includes:

- topology: existence, direction, degree contribution, connectivity role;
- geometry: length, area, thickness, volume, orientation;

## 5. NETWORK / EDGE EFFECTS

### Ω-LINK-1

This experiment family tests whether the placement and direction of individual edges can change system reachability even when node count and edge count remain fixed.

[Ω-LINK-1](https://github.com/SmartVoltISA/Omega-lab-.--.-/tree/main/experiments/Omega-LINK-1)

Key recorded results include:

- same nodes + same number of edges can produce different structural behavior;
- removing one edge always removes its immediate transition but global reachability loss can vary;

## 10. What is already supported vs what is not

### Already present as research material

- relation-first ontology as an explicit open research rule;
- relations treated as potentially stateful/measurable objects;
- experiments on edge placement and direction;
- relation interaction experiments;
- stable relation / attractor investigations;
- relation memory and breaking;
- emergent localized structures;
- physical cross-checks;
- relation evidence records in ORISIK;
- gravitational/black-hole-related relation hypotheses.

### NOT established

- that relations are physically fundamental;
- that relation structure is dark matter;
- that a relational field reproduces galaxy rotation curves;
- that the model explains lensing or clusters;
- that Ω-DM replaces particle dark matter;
- that any current relation experiment constitutes a cosmological proof.

## 11. Next stitching step

The next scientific task is not to invent another philosophical layer. It is to extract the **minimal common variables** from these existing branches and determine whether they can form a single quantitative model:

`relation state → interaction law → effective field/dynamics → observable gravity`.

Only after that should Ω-DM-001 be implemented.
