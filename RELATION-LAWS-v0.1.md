# Ω-DM — RELATION LAWS v0.1

Date: 2026-09-11
Status: EMPIRICAL/CANDIDATE RULES — NOT PHYSICAL LAWS

## Purpose

Extract the rules that are currently supported by the Ω-DM experiments and the common relation-state model. These are not claimed to be laws of nature. Each rule is a candidate invariant or modelling principle that must survive independent falsification tests.

## 1. Relational sufficiency rule

A hidden relation structure can carry predictive information about future state beyond a zero-relation baseline.

Evidence: Ω-DM-002 R3 and Ω-DM-004.

Required condition: predictive advantage must survive held-out evaluation and null/permutation controls.

## 2. Mechanism-independence candidate

The ability to recover predictive relational structure is not necessarily tied to one particular generator. Ω-DM-004 kept the R3 inference method fixed while changing the generator to bounded nonlinear tanh coupling and retained a 20/20 predictive advantage at every tested horizon.

Interpretation: candidate property of the inference problem, not evidence for a universal physical law.

## 3. Topology matters

Node count and edge count alone are insufficient in general to determine network behaviour. Edge placement, reachability and alternative paths can change global dynamics.

This is a graph-theoretic rule supported by controlled model experiments, not a new physical law.

## 4. Distributed redundancy

Predictive information need not reside in a single indispensable relation. Ω-DM-003 found no individually critical active edge under the frozen deletion test, while backward elimination produced smaller predictive cores.

Candidate principle: system-level function can be distributed across redundant relational pathways.

## 5. Predictive core is not generating graph

A minimal or reduced predictive core should not automatically be interpreted as the true generating topology. Order-dependent cores in Ω-DM-003 demonstrate this distinction.

Therefore topology reconstruction and predictive compression are separate scientific objects.

## 6. Propagation plus dissipation is not memory

A propagating state disturbance with decay does not by itself establish persistent relational memory.

Any memory variable must have an explicit update law and an independent retention test.

## 7. Relation has to be operational

A relation is scientifically meaningful only when its variables, update rule, units (if physical), and measurable consequences are explicitly defined.

Names such as strength, stiffness, memory, capacity or geometry do not acquire physical meaning by analogy.

## 8. Observation → relation → prediction

The strongest current computational chain is:

observed state → infer hidden relations → freeze inferred structure → predict held-out dynamics.

The prediction stage is the discriminator. A visually plausible graph is insufficient evidence.

## 10. Laws still to test

The next law-discovery campaign should test, independently and preregistered:

- scaling law: how relation effects change with system size;
- locality law: dependence on graph/geometric distance;
- symmetry law: invariance under relabeling, translation and allowed transformations;
- conservation law: whether any quantity remains invariant under closed dynamics;
- causality/propagation bound: whether influence has a finite or model-defined speed;
- composition law: whether multiple relations combine linearly, nonlinearly or saturate;
- threshold/breaking law: whether relations change regime at reproducible thresholds;
- path-dependence law: whether history changes future relation state;
- coarse-graining law: whether relational behaviour survives aggregation of nodes;
- noise law: how inference degrades with observation noise and missing variables.

## 11. Physical bridge remains unproven

No current result derives gravity, a gravitational field equation, Newtonian gravity, lensing, CMB behaviour, cosmological structure formation, or dark-matter phenomenology from the relational state model.

The required bridge remains:

relation state → explicit interaction law → coarse-grained effective dynamics → gravitational observable.
