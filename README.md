# Ω-DARK-MATTER / OMEGA-DARK-MATTER

**RU:** Исследование гипотезы о том, что гравитационные эффекты, приписываемые тёмной материи, могут возникать из скрытой структуры связей, а не из дополнительной материальной субстанции.

**EN:** Researching the hypothesis that gravitational effects attributed to dark matter may emerge from hidden relational structure rather than from an additional material substance.

**中文:** 研究这样一种假设：通常归因于暗物质的引力效应，可能源于隐藏的关系结构，而不是源于额外的物质成分。

---

## Status / Статус / 状态

**OPEN RESEARCH HYPOTHESIS — NOT ESTABLISHED PHYSICS**

This repository does **not** claim that dark matter has been explained, replaced, or experimentally disproven. Its purpose is to construct a falsifiable relational model and compare its predictions with observations and established dark-matter models.

---

## 1. Research question

Can some gravitational effects currently attributed to dark matter emerge from a hidden or implicit structure of relations between physical states, without introducing an equivalent additional particle substance?

The model must produce quantitative, testable predictions.

---

## 2. Core hypothesis Ω-DM

**H₁:** A hidden relational structure can generate an effective gravitational contribution that reproduces some observations normally modeled using dark matter.

**H₀:** The proposed relational structure provides no predictive advantage over appropriate established baselines once model complexity and parameters are controlled.

A fit alone is insufficient evidence.

---

## 3. Relation-first model

```text
DISTINCTION
    ↓
RELATION
    ↓
RELATIONAL STATE
    ↓
INTERACTION / TRANSITION
    ↓
EFFECTIVE FIELD OR DYNAMICAL CONTRIBUTION
    ↓

```

The central question is whether an apparently missing source of gravity can instead be represented by a hidden relational degree of freedom.

This is a model-building hypothesis, not an established claim about the fundamental substance of nature.

---

## 4. First target

The first practical target is **galactic dynamics**, especially rotation curves.

Compare:

1. visible-matter-only baseline;
2. standard dark-matter baseline;
3. minimal Ω-DM relational model.

Whenever possible, calibration and final evaluation must use separate data.

Later stages may address gravitational lensing, galaxy clusters, cosmological structure and other independent constraints.

---

## 5. Evidence standard

A meaningful result requires more than visual similarity to a known curve:

- explicit mathematical model;
- fixed assumptions and parameters before the final test;
- identifiable relation/state variables;
- reproducible computation;
- quantitative goodness-of-fit metrics;
- complexity/parameter penalty;
- comparison with established baselines;
- out-of-sample or held-out validation;
- sensitivity analysis;
- attempts to falsify the model;
- preservation of failed experiments and negative results.

A successful fit obtained only by adding enough free parameters is **not** evidence for Ω-DM.

---

## 6. Falsification rules

Ω-DM must actively try to fail.

Possible controls include:

- randomizing or destroying relational structure;
- replacing relations with appropriate null models;
- changing initial conditions;
- perturbing parameters;
- testing galaxies outside the calibration set;
- comparing against conventional dark-matter models;
- controlling model complexity;
- checking whether the same mechanism makes incorrect predictions elsewhere.

If the relational effect disappears under controls, that failure is recorded as a result.

---

## 7. Scientific boundaries

This project does **not** currently claim:

- that dark matter does not exist;
- that dark matter particles have been ruled out;
- that gravity is caused by relations;
- that relations are the fundamental substance of the Universe;
- that one successful galaxy fit proves a cosmological theory;
- that Ω-DM replaces ΛCDM or general relativity.

Any stronger claim requires independent evidence.

## 9. Initial experiment roadmap

### Ω-DM-001 — Minimal relational gravity model
Define the smallest mathematically coherent model in which relational state contributes to an effective gravitational term.

### Ω-DM-002 — Synthetic validation
Create controlled systems with known relational contributions and test recovery.

### Ω-DM-003 — Rotation-curve baseline comparison
Compare visible matter, standard dark-matter baseline and Ω-DM on observational data.

### Ω-DM-004 — Null and permutation controls
Destroy or randomize relational structure while preserving relevant low-level statistics.

### Ω-DM-005 — Cross-galaxy validation
Calibrate on one population and test on independent galaxies.

### Ω-DM-006 — Independent replication
Reproduce the result using an independently implemented analysis path.

### Ω-DM-007 — Beyond rotation curves
Only if earlier tests survive: investigate lensing, clusters and cosmological constraints.

## 12. Philosophy

The project asks a narrow scientific question:

> **Can a hidden structure of relations produce measurable gravitational effects that are currently modeled as an additional source of mass?**

If the answer is no, that is a useful result.

If the answer is yes, the next question is whether the model survives independent observations and competing explanations.

**Use it. Test it. Break it. Reproduce it.**
